# 阶段 3：深度边缘辅助 DIS

状态：待阶段 2 仍无法稳定处理白模轮廓时实施，当前不可调用。

## 问题

当前网格颜色接近统一浅灰色。大面积表面缺少纹理，DIS 主要依靠模型轮廓、线框和
光照梯度估计运动，容易在平坦区域产生不确定流场。

## 方案

在可视化阶段同时捕获：

- RGB 渲染图；
- Open3D 深度图；
- 由深度图生成的归一化深度边缘。

使用灰度、线框和深度边缘组成光流输入，但最终 Warp 的仍然是正常 RGB 渲染图。
深度数据不发布到 ROS，也不修改重建输出。

## 修改范围

仅修改可视化包：

- 使用 Open3D `CaptureDepthFloatBuffer()`；
- 增加深度归一化和边缘提取；
- 为插值器增加光流输入图与最终显示图分离的接口；
- 新增阶段 3 YAML 和 launch。

## 预期调用

阶段 3 完成后将提供：

```bash
ros2 launch visualization v_dis_depth_edges.launch.py
```

在对应 launch 文件提交前不要使用此命令。

## 计算开销

- 增加一次深度缓冲捕获；
- 增加深度归一化和边缘计算；
- DIS 和 Warp 次数与阶段 2 基本一致；
- 内存需要额外保存前后两张低分辨率深度特征图。

## 验收重点

- 白模内部和轮廓的流场是否更稳定；
- 深度无效值是否造成大面积边缘噪声；
- 地面与目标交界处是否减少相互拖拽；
- 深度捕获是否明显拖慢 Open3D 渲染。
