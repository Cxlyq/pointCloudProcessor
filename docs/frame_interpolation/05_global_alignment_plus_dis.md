# 阶段 4B：全局预对齐加 DIS

状态：可选增强，当前不可调用。

## 目标

两秒的真实帧间隔可能导致像素位移过大。先估计并消除主要的全局平移、旋转和缩放，
再让低分辨率 DIS 只估计剩余的局部运动，可降低光流搜索难度。

## 流程

```text
I0、I1
  ↓
估计全局仿射变换
  ↓
把 I1 预对齐到 I0
  ↓
对残差计算低分辨率 DIS
  ↓
组合全局变换和局部光流
  ↓
生成中间画面
```

## 修改范围

仅修改可视化插值器，并新增独立配置和 launch。上游流水线不变。

## 预期调用

完成后将提供：

```bash
ros2 launch visualization v_global_dis.launch.py
```

在对应 launch 文件提交前不要使用此命令。

## 计算开销

比纯 DIS 多一次低成本全局配准，但可能允许：

- 使用更低分辨率的 DIS；
- 减少 DIS 迭代或使用 ULTRAFAST；
- 降低大位移造成的错误流场。

## 启用条件

- 阶段 1 或阶段 2 在大位移场景中失败；
- 同时存在明显全局运动和少量局部运动；
- 全局变换估计具有稳定内点；
- 单纯提高 DIS 质量预设仍无法解决问题。
