# 延后方案：RIFE 神经插帧

状态：不在当前实施计划中。

## 保留原因

RIFE 仍然可以只处理渲染后的两张图，不必改变点云流水线，因此没有违反项目边界。
但它会引入模型文件、深度学习运行时以及较高的 CPU/GPU 和内存需求，不符合当前
“弱硬件、先验证低成本方案”的目标。

## 何时重新评估

只有在以下条件同时成立时再考虑：

- 双向 DIS、深度边缘和全局预对齐仍无法达到可接受质量；
- 目标机器具有可用 GPU 或可接受的推理时间；
- 可以接受部署模型和运行时依赖；
- 需要更强的遮挡与新显露区域生成能力。

## 调用说明

当前没有 RIFE 模型、运行时适配或 launch 文件，因此不可调用。若未来实施，仍应作为
`visualization_node` 内部或其后的纯图像显示组件，不得修改现有点云和重建流水线。
