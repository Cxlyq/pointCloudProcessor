# 阶段 4A：全局仿射插帧

状态：可选方案，待实际画面证明“整幅图主要统一运动”后实施，当前不可调用。

## 适用条件

- 主要变化是整体平移、旋转或缩放；
- 前景和地面基本具有相同运动；
- 视差和独立目标运动较少；
- 优先追求最低计算量。

若相机固定而不同目标独立变化，该方案通常不如 DIS。

## 方案

对相邻渲染图提取轮廓或特征，估计一个全局仿射矩阵。将矩阵分解为平移、旋转和
缩放，对这些参数按时间比例插值，再 Warp 前后两张图并融合。

可按画面特点选择：

- 相位相关：只估计纯平移，速度最快；
- ECC：适合低纹理灰度配准；
- ORB、特征匹配和 RANSAC：可估计旋转、缩放和平移。

## 修改范围

仅增加可视化图像配准器、独立配置和 launch，不改变上游流水线。

## 预期调用

完成后将提供：

```bash
ros2 launch visualization v_global_affine.launch.py
```

在对应 launch 文件提交前不要使用此命令。

## 计算开销

每对真实帧只估计一个全局矩阵，随后生成19张 Warp 图像。其计算量低于所有 DIS
方案。

## 失败条件

- 不同深度存在明显视差；
- 多个物体独立运动；
- 模型局部出现或消失；
- 全局匹配内点比例低；
- 大面积形变无法由单个矩阵表达。
